# Ритм дня

Адаптивный дневник питания, воды и расходов на еду на Next.js и TypeScript.

## Запуск

1. Установите Node.js и выполните `npm install`.
2. Запустите `npm run dev`.
3. Откройте `http://localhost:3000`.

Регистрация и вход отключены: приложение сразу открывает дневник и не требует `.env` или секретов авторизации. Записи, настройки и лимиты сохраняются в хранилище текущего браузера; фотографии и чеки — в IndexedDB этого же устройства. Данные не передаются на сервер и не синхронизируются между устройствами. Для резервной копии используйте экспорт в разделе настроек.

## Данные и приватность

- «Удалить данные» очищает дневник, настройки и вложения текущего браузера.
- Фото блюда и чек хранятся отдельно; удаление фотографии не удаляет запись.
- Очистка данных сайта или смена браузера может удалить локальные данные.
- `.env.example` содержит только необязательные параметры для ручного запуска исторических Turso-миграций. Приложение их не использует.

## Проверка и сборка

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Vercel и GitHub

Импортируйте репозиторий `xinz37759-collab/Water` в Vercel и оставьте стандартные команды Next.js (`npm install`, `npm run build`). Для текущего локального режима переменные окружения не нужны. GitHub хранит исходный код, а Vercel размещает приложение; пользовательские данные остаются в браузере.
